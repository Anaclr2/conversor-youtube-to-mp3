# 🎵 Conversor YouTube para MP3

Aplicação web moderna desenvolvida para simulação e conversão de vídeos do YouTube em arquivos de áudio MP3, com interface responsiva em modo escuro, pré-visualização de capas e acompanhamento do fluxo de download.

![Preview do Conversor](conversor-preview.png)

## 🚀 Funcionalidades Principais

- **Design Dark Mode:** Interface limpa e intuitiva inspirada no visual do YouTube, otimizada para computadores e dispositivos móveis.
- **Entrada de Links:** Campo dedicado para colagem da URL do vídeo do YouTube.
- **Pré-visualização do Vídeo:** Exibição da imagem de capa (thumbnail), título completo, duração e opções de qualidade do áudio (ex: 128kbps, 320kbps).
- **Simulação de Download:** Fluxo visual interativo com barra de progresso em tempo real e tela de confirmação de geração de arquivo.
- **Histórico de Conversões:** Lista com os últimos vídeos convertidos na sessão para facilitar novos downloads.

## 🛠️ Tecnologias Utilizadas

- **Backend:** PHP
- **Armazenamento / Dados:** JSON (`db.json`)
- **Frontend:** HTML5, CSS3 (Estilização personalizada dark mode) e JavaScript (Manipulação de interface e simulação de progresso)
